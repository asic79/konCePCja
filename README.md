# GX4000 hardware evidence

Photographs of test cartridges running on a real Amstrad GX4000 (with a
PicoGX cartridge where noted), referenced by pull requests to
ikari-pl/konCePCja. Cropped to the screen; no metadata.

- `A_*`: ASIC DMA step timing; PSG register selection under DMA.
- `B_*`: Plus split line, raster interrupt timing, horizontal soft-scroll
  edges, palette changes inside a character.
- `C_*`: PicoGX save channel timing, three power-ups.
- `D_*`: power-on RAM contents, three power-ups.
